## 🚀 Projets phares

[**immo-compare-94**](https://github.com/sferrad/immo-compare-94) : Comparateur immobilier du Val-de-Marne 🏠 — Next.js 16 / React 19 / TypeScript / Tailwind côté front, FastAPI / pandas / shapely côté back, carte interactive Leaflet et graphiques Recharts, données DVF (data.gouv.fr). Déployé sur Vercel + Railway.

[**ft_transcendence**](https://github.com/sferrad/ft_transcendence) : Plateforme web full-stack 🖥️ containerisée (React/TypeScript + microservices FastAPI) avec API Gateway, services User/Chat/Friends/Game/Profile/Analytics, PostgreSQL par service, Redis, auth JWT, secrets via Vault, WAF (Nginx/ModSecurity) et monitoring Prometheus/Grafana/Alertmanager. (En développement...)

[**webserv**](https://github.com/sferrad/webserv) : Serveur HTTP/1.1 en C++98 🌐, configuration type nginx, multi-ports, epoll, CGI (Python/PHP), upload, autoindex, redirections et gestion native des cookies.

[**Inception**](https://github.com/sferrad/Inception) : Infrastructure Docker 🐳 orchestrant Nginx (reverse-proxy SSL), WordPress et MariaDB via Docker Compose, avec volumes persistants et réseau interne isolé.

[**IReversibleShell**](https://github.com/sferrad/IReversibleShell) : Reverse shell éducatif en Python 🐍, pour comprendre le fonctionnement des shells inversés dans un cadre légal et pédagogique.

[**Keyser Soze**](https://github.com/sferrad/Keyser-Soze) : Keylogger Python 🕵️, conçu à des fins pédagogiques pour démontrer la capture de frappes clavier et d'interactions souris dans un cadre sécurisé.
